# Tools — product inventory and conformance

> **Scope:** this is the frozen v3 vendor-conformance baseline, not the complete
> v21 tool inventory. The canonical v21 world retains these 91 tools and adds 19
> RetailGuard plus 990 CounselOps tools, for 1,100 agent-visible tools total.
> Only the 91 rows below carry vendor-target conformance claims; the 1,009 added
> tools are executable synthetic legal-operations contracts, not certified
> replicas of proprietary products. See [the v21 release audit](V21-RELEASE-AUDIT.md).

The evaluated baseline contains **91 agent-visible tools across 9 mirrored products**.
Every name is partitioned exactly once by `mcp/systems.json`; simulator-only actuators are excluded from MCP discovery.
Request, response, pagination, error, live-diff, and fidelity-ceiling evidence is generated by `tools/conformance/`.

- 47/91 are exact to a pinned machine-readable public contract.
- 85/85 pass the best public verification available.
- 6 iManage operations remain explicitly partner-gated.
- 0 agent-visible simulator-extension gaps; 0 conformance-harness failures.

See [the conformance matrix](CONFORMANCE.md), [product justification](MCP-JUSTIFICATION.md), and [generated API pages](api/V3-README.md).
