# V21 seeded document corpus

This directory is generated by `tools/build_v21_seed_documents.py`. It contains
66 fully synthetic evidence packs spanning 22 legal practice domains and three
variants per domain. Each pack contains:

- `matter-brief.docx` — a styled, US-Letter brief with pinned facts, work
  requirements, and an explicit validation boundary;
- `evidence-register.xlsx` — a three-sheet register with formulas and control
  instructions; and
- `source-extract.pdf` — a one-page source excerpt.

Variants 02 and 03 are seeded mutations of variant 01. They preserve the same
OOXML/PDF structure while changing synthetic parties, facts, amounts, dates,
and required work. The documents are evidence inputs, not legal advice. Every
pack requires attorney validation and labels itself synthetic.

`catalog.json` maps packs to task file lanes. Each pack-local `manifest.json`
records SHA-256 hashes and a common structure signature. `build-report.json`
publishes aggregate counts.

```bash
python3 tools/build_v21_seed_documents.py
python3 tools/build_v21_seed_documents.py --check  # isolated byte comparison
```

The build normalizes OOXML member order/timestamps and uses invariant PDF
metadata, so identical source code produces byte-identical documents.
The structure signature also pins the DOCX one-page layout margins/body style
and each worksheet's landscape Letter print area with fit-to-one-page settings.
Release validation rendered and visually inspected all 330 resulting pages
(66 DOCX, 198 worksheet pages, and 66 PDF pages) with no clipping or orphaned
content.
